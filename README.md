# Mazhwetu General Works — Premium Website

Next.js / TypeScript / GSAP / ScrollTrigger / Lenis / Locomotive Scroll.

## Install

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```

## Notes

- Home uses Lenis for smooth scrolling.
- Projects uses Locomotive Scroll in isolation. Do not run both engines on the same page.
- GSAP ScrollTrigger drives reveal and image-motion behavior.
- Replace the reference Unsplash imagery with authentic Mazhwetu project photography before launch.
- Contact currently uses phone/email actions rather than a fake backend form. A real enquiry endpoint can be added once the client's preferred mail/service integration is known.
- The source strategy and hierarchy are documented in `docs/strategy.md`.
