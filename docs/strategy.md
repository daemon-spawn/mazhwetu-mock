# Mazhwetu General Works — Website Strategy

## Primary job
Turn a first-time visitor into a qualified project enquiry by making Mazhwetu's offer, capability, work and next step obvious.

## Audience
Residential, commercial, private-estate and development visitors seeking construction, renovation, landscaping, outdoor-space or maintenance work.

## Information order
1. Hero: what Mazhwetu does + context + action.
2. Proof strip: established / execution / client contexts.
3. Positioning: “Value Created In Our Execution”.
4. Services: grouped into five clear service families so the full list is understood without a wall of cards.
5. Audience band: visitor self-identification.
6. Work: strongest visual proof, with dedicated Projects route.
7. Design & visualisation: adds process clarity without inventing claims.
8. Approach: understandable project journey.
9. Trust: established year, service reach, quality and after-sales positioning.
10. CTA: email or phone.

## Visual direction
- Deep forest and near-black should carry the strongest moments: hero, services, process, footer.
- Warm off-white provides breathing room for work, typography and long-form scanning.
- Green is an action / emphasis colour, not decoration sprayed across the page.
- Typography is intentionally restrained: strong sans-serif display scale + neutral system body copy.
- Visual language: architectural crops, material detail, landscape geometry, clean edges, controlled contrast.
- No generic icon grid, no testimonial inventions, no fake client logos, no meaningless statistics.

## Interaction language
- Lenis is the active smooth-scroll layer on the home page.
- Locomotive Scroll is isolated to the Projects route so the app does not run two scroll engines simultaneously.
- GSAP ScrollTrigger handles viewport reveals and image scale-ins.
- Reduced-motion disables non-essential movement.
- No scroll hijacking, long transition gates or hover-only information.

## Content integrity
Project imagery is explicitly temporary reference photography because the supplied build brief did not include authentic Mazhwetu project images. Those images must be replaced before launch with real project photography, captions and any verified project metadata.

## Conversion
Primary CTA is “Start a project” and consistently lands at `#contact`. Secondary route is “View the work”. The contact area provides both phone and email so visitors are not forced into a single channel.
